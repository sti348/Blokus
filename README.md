# 角斗士棋（Blokus）

网页版角斗士棋，支持 **1–4 名玩家同屏对战**，空位可以交给三档难度的**电脑**。纯 HTML / CSS / JavaScript，不需要安装或构建。

## 开始游戏

直接用浏览器打开 `index.html` 就能玩（离线可用，只有标题字体需要联网加载）。

也可以起一个本地静态服务器，例如：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 玩法

- 每人 21 块棋子（1–5 格，共 89 格），按 **蓝 → 黄 → 红 → 绿** 轮流落子。
- 第一块必须盖住自己的起始角。
- 之后每块都必须与自己的棋子**角对角**相接，且自己的棋子之间**不能边贴边**（与别人的棋子边贴边没关系）。
- 无处可放的玩家自动出局，所有人都放不下时对局结束。
- 计分：每个未放置的格子 −1；21 块全部放完 +15，最后一块是单格再 +5。

### 模式

| 模式 | 棋盘 | 参战方 |
| --- | --- | --- |
| 标准 | 20×20 | 2–4 方，每个座位可设为玩家 / 电脑 / 空位 |
| 双人 | 14×14 | 2 方，起点在棋盘内侧 (5,5) 与 (10,10) |

快速开局预设：1 人 + 3 电脑、2 人 + 2 电脑、3 人 + 1 电脑、4 人同屏、电脑观战。

### 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 选棋子 | 点击右侧托盘 | 点击下方托盘 |
| 移动 | 鼠标移到棋盘上，或方向键 | 在棋盘上点击 / 拖动 |
| 旋转 | `R`（`Shift+R` / `E` 逆时针）、右键、滚轮 | 旋转按钮 |
| 翻转 | `F`、鼠标中键 | 翻转按钮 |
| 放置 | 左键单击、回车 | 再点一次同一格，或按“放置” |
| 提示 / 悔棋 | `H` / `Ctrl+Z` | 顶部按钮 |

其他功能：可落子角点提示、当前没有位置的棋子会以虚线标出、悔棋（会连同之后电脑的回合一起撤回）、中途“停手”、对局自动保存（返回菜单后可“继续上局”）、浅色 / 深色主题、音效开关。

## 电脑难度

- **简单**：随机落子，偏向大块棋子。
- **普通**：贪心估值，考虑棋子大小、新增角点、占掉对手的角点、开局向中心扩张。
- **困难**：先用贪心筛出候选，再模拟落子，比较自己与对手剩余的可行步数和还能放下的棋子；对手越少，越重视压制对手。

自对弈测试（标准盘，两两交替座位）中困难的平均分明显高于普通，普通又远高于简单；每步计算通常只需几到几十毫秒。

## 项目结构

```
index.html        页面结构
css/style.css     样式（含深色主题与窄屏布局）
js/pieces.js      21 块棋子及其旋转 / 翻转
js/engine.js      规则引擎：合法性检查、走法生成、轮转、计分、重放
js/ai.js          电脑玩家
js/app.js         界面与交互
tests/            规则引擎与电脑的单元测试
```

`pieces.js`、`engine.js`、`ai.js` 不依赖 DOM，可以在 Node 中直接使用。

## 测试

```bash
npm test
```

测试会把走法生成结果与暴力枚举逐一比对，并跑完整的随机对局，检查终局与重放的一致性。
